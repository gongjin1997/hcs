# GaussDB 页面重构与系统整理（2026-11-03）

## 本次解决的问题

旧页面把实例、磁盘、节点、巡检报告、SQL、会话挤在一个组件里。切页签会丢失节点选择和查询结果；实例详情没有 URL，刷新或从台账跳转都不能定位；项目筛选要求用户输入内部编号。系统菜单把五类作业各列一项，告警入口与规则、通知分离，系统管理又平铺八个标签。

当前版本按日常查看流程重新组织：先选实例，再查看该实例的概览、磁盘、巡检性能、慢 SQL、会话。资源属于谁、在哪个项目、数据是什么时间，始终跟随当前实例。后台采集设置、告警规则和在线查看仍各自负责原有业务，不在监控页面重复增加配置入口。

## GaussDB 页面

- **实例列表**：按项目名称选择、名称或云实例 ID 搜索；显示运行状态、巡检状态与台账更新时间。项目选项来自当前可见的 GaussDB 台账，查询不请求云。
- **实例定位**：`/gaussdb?instance_id=<本地主键>&tenant_id=<租户>&tab=<页签>`。从台账、关联告警打开，或刷新页面，都定位到同一实例；不依赖当前列表页中是否存在目标。
- **概览**：配置与台账更新时间、节点和组件。配置 CPU、内存不作为使用率。节点表从磁盘页移出。
- **磁盘**：实例级已用、总量、使用率；本地已采集历史独立展示。源接口没有分节点磁盘用量，不编造分节点图表。
- **性能与巡检**：左侧完成记录，右侧报告、CPU / 内存分类与节点指标，检查结果直接可见；原始采样按检查项展开。报告缺少某指标时显示缺失，不补零、不拼成实时曲线。
- **慢 SQL**：按时间、文档支持的节点、秒级阈值查询；结果耗时保留微秒，详情和执行计划只读。
- **会话**：只允许 CN 或 DN 主备组件；主要筛选与高级筛选分开。没有结束会话、执行 SQL 或扩容操作。
- **上下文与结果**：同实例切页签保留各自结果和筛选；切实例、切租户、权限变化取消在途请求并清除旧范围数据。顶栏统一刷新；导出在各表格/报告标题栏，导出条件来自已完成查询。

组件边界：`GaussView` 负责路由和权限；`GaussInstanceList` 负责目录；`GaussWorkspace` 负责实例上下文；`GaussPerformancePanel`、`GaussQueryPanel` 负责各自流程。`useGaussPanel` 管理请求取消、结果归属和各页签缓存，容量历史继续使用独立历史查询模块。

## PDF 核对

以本地 `gaussdb-api.pdf` 为依据，正文页码与阅读器物理页相差 10 页：

| 能力 | 正文页 | 使用边界 |
| --- | --- | --- |
| 存储使用量 | 25–27 | GB，实例级；记录接收时间，不冒充源采样时间 |
| 节点组件 | 109–116 | 查询分页；DN 主备角色/状态有证据才可用于会话 |
| 完成巡检记录、详情 | 372–384 | CPU / 内存源于报告；时间、节点和单位来自原始数据 |
| 慢 SQL 节点、列表、详情 | 384–395 | 时间为请求 UTC 毫秒；阈值秒，耗时微秒；不杜撰分页 |
| 实时会话 | 422–427 | CN 或 DN 主备；最多 200，源端没有总数/分页 |

本轮修复组件分页提前结束、重复节点、总数冲突等不完整响应，以及冷备/日志/仲裁 DN 被误当成可查询组件的问题。新增两条本地目录查询；云查询路径和只读白名单保持不变。AOM 不启用。

详细合同见 `GaussDB页面重构_API合同_20261103.md`。系统入口、分区、权限与旧链接兼容见 `系统导航与功能归属_20261103.md`。
