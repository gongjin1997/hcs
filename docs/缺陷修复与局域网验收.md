# 缺陷修复与局域网验收

日期：2026-10-25。范围：上一轮分析确认的资源隔离、会话撤销、前端请求竞态、PostgreSQL 测试缺口、采集与查询性能问题。

## 已实现

- **资源隔离**：迁移 0004 为项目资源 / 无项目历史资源建立部分唯一索引；巡检与台账同步按租户和项目匹配，不能移动其他项目记录；Excel 按租户 / 类型消歧；ECS 重启统计关联本项目资源；CCE 工作负载下线同时限制租户和项目。
- **会话失效**：迁移 0005 增加用户 token_version 和 revoked_token；改密、重置、停用失效旧令牌，退出撤销当前会话；撤销持久化，跨进程 / 重启有效，不依赖 Redis；SSE 票据和连接检查会话及权限。
- **列表竞态**：仅最新请求更新 rows / total / loading；忽略旧错误，卸载后不更新；搜索重置页码不会重复发请求。
- **PostgreSQL**：全套测试可运行于 PostgreSQL 16，按运行 / 用例创建随机 schema，只删除自己创建的 schema；CI 增加 PG 作业；真实 PG 回归发现并修复租户删除时子项目外键顺序。
- **采集 / 性能**：DataArts 路径参数编码、有界并发、401 并发单次刷新；并发 / QPS 可在系统设置调整；统计调用量 / 错误 / 等待并存入任务记录。巡检批量预取状态、静默及通知路由；资源列表使用 SQL 排序分页。
- **前端与接口防护**：退出调用后端，改密后返回登录；页面 CSP 与 Swagger 专属 CSP；新增 Vitest 5.0.5，ECharts 6.1.0，Node 22.12+；npm audit 无已知漏洞。

## 启动与运行边界

```bash
make lan
make lan-status
make lan-stop
# 自定义当前机器的绑定地址
python3 scripts/lan.py start --host <LAN_IP> --port 5173
```

本机入口：`http://<LAN_IP>:5173`。演示管理员：`admin / admin123`；只读或值班演示账号在登录页 / 演示种子中定义。

- 独立 PostgreSQL 16：回环端口 55433，专用持久卷；Redis：回环端口 16379。
- API：127.0.0.1:18000；Mock HCS：127.0.0.1:19000；Mailpit SMTP：127.0.0.1:11025，收件箱仅本机 127.0.0.1:18025。
- 前端使用构建后的静态产物与 Vite preview 代理；调度和通知为独立后台进程，退出启动命令后继续运行。
- `.runtime/lan/config.json` 保存本模式随机生成的数据库 / JWT / 加密密钥，权限 600；目录和日志被 Git 忽略。`INSPECTOR_ENV_FILE=` 禁用已有 .env，未接入真实 HCS 或企业 SMTP。
- 更新代码后 `make lan-stop && make lan`。stop 只终止已记录且启动标识匹配的进程、带本项目标签的容器，保留演示数据库；不操作其他项目服务。
