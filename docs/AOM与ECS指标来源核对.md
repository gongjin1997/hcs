## 当前 ECS 策略

- 所有资源（含 ECS）都不选择或请求 AOM；即使有 Endpoint、专用映射或旧可用记录也不启用。
- 租户旧 `metrics_source=AOM` 保留但有效来源为 `NONE`。普通编辑允许保留旧值，显式新选 AOM 被拒绝。
- `AUTO` 忽略旧 AOM 映射；已配置租户 Prometheus 时仍可使用，否则显示未接入，不补零。
- 任务或策略的新非 null AOM 映射被拒绝；可传 `aom:null` 清除。普通调度编辑不改动无关参数。
- 租户检测和 probe 直接跳过 AOM，不认证、不请求元数据或样本，不将旧地址不可达计为故障。
- 旧 AOM 样本和探测结果仅保留作历史，不当作当前使用率或告警证据。
