# DCS 监控交接合同（2026-11-02）

## 范围与证据

原生只读 DCS V2；不调用 AOM/CES，不进行 V1 自动 fallback。证据为 `dcs-api.pdf` §4.2.6 表4-81 与 §5.2.2 表5-36。V2 `used_cpu` 为累计秒；历史 V1 同名字段为百分比，**V1 CPU% 尚未启用**。V2 统计没有实例连接数，不从节点会话拼接连接数。

## API

- `GET /api/v1/dcs/instances`：原有筛选/分页不变。增补 `used_cpu_seconds,input_kbps,output_kbps,keys,cmd_get_count,cmd_set_count`；原有内存字段继续使用 MB/百分数。
- 当前值元数据：`metrics_source=DCS|NONE`、`api_version=v2|null`、`source_endpoint=instances/statistic|instances|null`、`metrics_observed_at`、`time_basis=RESPONSE_RECEIVED`、`freshness=FRESH|STALE|NO_DATA|LEGACY`、`sample_age_sec`、`stale_after_sec`、`warning`。`snapshot_at` 仍是资源快照时间，不能据此推定指标新鲜度。
- 无有效原生来源或响应时间、已过期、旧 AOM/CES 的快照：当前指标为 null；保留来源/时间状态，禁止旧值伪装为当前值。阈值继承采集策略，默认 900 秒。
- 保留 `/dcs/history` 与 `/dcs/export` 内存合同，继续查询原有真实内存样本。
- 新增 `/dcs/metrics/history` 与 `/dcs/metrics/export`，查询参数与内存接口相同：`resource_ids` 重复参数（1–20个）、带时区 `start_at,end_at`（最长31天，含起点不含终点）、`interval_minutes=5|10|15|30|60`。
- 返回 `metrics[]` 声明 `key,label,unit,aggregation`；`series[].points[]` 为原生字段，另有 `last_observed_at`（末次本地响应获取时间）、`sample_count`、`metric_sample_counts`。`series[].summaries` 保留每个指标的真实样本统计；累计量没有 average。
- 单位/聚合：内存使用率 `%`、已用内存 `MB`、网络 `kbit/s` 取窗口均值；容量 `MB`、CPU累计 `s`、keys与GET/SET计数 `count` 取窗口末值。0有效，缺失为null；重启后的计数重置保留原值，不换算 CPU%/QPS。
- 本地查询/导出不触发云请求；全部接口沿用 `report:view`、租户授权与资源范围验证。

## 持久化与共享接线

迁移 `0012`，`down_revision=0011`；新增 `dcs_metric_sample`，一资源一本地接收响应时刻一行，保存租户/项目、版本、接口、本地响应获取时间、入库时间及9个指标，不回填历史。旧内存表继续写入。

共享文件仅窄改 DCS 接线：`models/__init__.py` 导出 DCS 模型；`pipeline.py` 调用 DCS 专属保存函数、内存采样采用观测响应时间；`cleanup.py` 按90天分批清理 DCS 样本及孤儿。修改前后保留 Gauss/ECS 导入调用。

前端保持 `/dcs` 路径和页面文件名；菜单/路由对应DCS一行名称改为“DCS监控”（界面依项目排版为“DCS 监控”）。查询/Excel置于表头搜索右侧，刷新通过 `PageHeader`。设计 token 沿用项目现有值。

## 时间语义补充

DCS V2 统计响应未提供源端采样时间。`metrics_observed_at`、样本 `observed_at`、`points[].last_observed_at` 和统计 `latest_at` 为兼容保留的字段名；本轮新记录的实际含义均为 **本地获取响应的时间**，`time_basis=RESPONSE_RECEIVED`。不得据此声称源端在该时刻采样，`FRESH/STALE` 仅判断本地获取记录是否过期，不能证明源端数据延迟。当前表、趋势明细和 Excel 均使用“获取时间”/“本地记录时间”标签。旧内存记录保持原有时间值，不回写为源端时间。

时间语义修正后复验：DCS 前端 70 项、相关后端 89 项通过；全量前端 709 项与全局 typecheck 通过；1440/390px 截图已更新，表头确认为“新鲜度 / 获取时间”，附源端未提供采样时间说明。
