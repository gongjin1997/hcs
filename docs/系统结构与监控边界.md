# 系统结构与监控边界

## 系统负责什么

HCS-Inspector 对已有云环境进行只读采集、资源登记、巡检、告警跟踪和报表导出。平台内可以管理规则、负责人、通知和任务配置；云端不执行资源变更、SQL 执行或会话终止。

公有云 CES、ManageOne 或其他监控产品的功能，不代表当前 HCS 版本已提供同样的 API。接口实现以对应版本的文档和实际响应为准。AOM 继续全局停用。

## 页面归属

| 一级入口 | 页面职责 | 地址 |
| --- | --- | --- |
| 运行总览 | 已知异常、巡检健康、资源与作业概况 | `/dashboard` |
| 资源监控 | 监控覆盖、ECS、DCS、GaussDB | `/monitoring`、`/ecs`、`/dcs`、`/gaussdb` |
| 容器事件 | 容器事件与工作负载上下文 | `/pod-events` |
| 作业运行 | DGC、Flink、实时、批作业、MRS | `/job-reports/*` |
| 资源台账 | 云资源身份、归属、负责人及变更 | `/ledger` |
| 报表中心 | 周期统计和导出 | `/reports` |
| 告警管理 | 告警、规则、通知、维护与静默 | `/alarms`、`/rules`、`/notify`、`/silences` |
| 系统管理 | 接入与采集、人员与权限、系统设置 | `/system` |
| 资源与指标指南 | 指标含义、单位、限制及技术字段 | `/guides` |

同一业务使用同一套页内导航。已有页面地址和权限点保留。侧栏入口指向该用户实际有权访问的子页；能进入工作区不代表能访问其中所有页面。

## 公共实现放在哪里

| 职责 | 当前实现 | 不在这里做的事 |
| --- | --- | --- |
| 工作区入口、标题、权限、选中项 | `frontend/src/config/workspace-navigation.ts` | 在菜单和页面分别复制服务字典 |
| 实例链接与范围校验 | `frontend/src/config/resource-navigation.ts` | 将云端 ID 或当前筛选猜作本地主键、所属租户 |
| 显式租户请求头 | `frontend/src/api/scope.ts` | 用空请求头代替“全部已授权租户” |
| 租户切换时 URL 和页面状态 | `tenantChangeQuery()`、`tenantViewKey()` 与列表 scope watcher | 留下另一个租户的资源 ID；在抽屉关闭动画中强制卸载 Tab |
| 顶栏刷新 | `PageHeader.vue` 与 `BasicLayout.vue` | 各页面再画一组全局刷新按钮 |
| 资源类型与字段说明 | `services/catalog.py`、`services/resource_guides.py` | 在覆盖页重新维护一份指标能力表 |
| 巡检证据是否有效 | `services/inspection_health.py` | 用资源存在或采集成功推断健康 |
| 监控覆盖汇总 | `services/monitoring_overview.py` | 查询云端、修改开关、补造采样值 |
| 云接口边界 | `hcs/readonly.py` 与各服务适配器 | 将故障处理建议直接变成云端写操作 |

覆盖页分别读取租户、项目、已有开关、任务、ECS 策略和巡检证据。它不产生另一套配置。完整巡检、部分巡检、过期和未知分别统计；已知异常即使过期也保留核查提示。

台账和告警列表在租户切换时保留页面实例，由 scope watcher 同步清空行、计数、选中项和详情，并中止旧请求；其他带实例上下文的页面切换租户时重挂载。列表详情抽屉先关闭，避免 Tab 面板在 Teleport 过渡尚未结束时被父页面抢先卸载。

## 一条资源的访问路径

1. 总览按服务进入监控或作业页；只巡检的作业不跳到资源台账。
2. 台账和告警使用同一个监控链接生成器，带上资源本地主键和明确租户。
3. 实例页面通过本地单实例查询定位，不依赖列表第一页或名称模糊搜索。
4. 返回台账或告警时保留资源身份；切换租户或权限变化时清空旧上下文，迟到响应不能重新打开旧实例。
5. 导出沿用已经应用的查询范围，输出 XLSX。页面时间窗口与原始指标单位不由导出逻辑重新解释。

## 增加新服务时的检查项

- 先确认文档版本、查询接口、分页、字段单位和时间含义；无证据的能力标为未支持。
- 在适配层解释原生字段，在服务层组织查询，在界面层展示；不要把接口兼容分支塞到组件里。
- 复用资源字典、指南、范围校验和导航定义。仅因增加一个面板，不新增一级菜单或独立配置源。
- 资源状态、台账快照、指标采样、巡检求值和历史报告时间分别处理。缺失值不能补零，历史报告不能显示成实时指标。
- 验证只读边界、租户与角色范围、分页之外的实例定位、切换时的迟到响应、空值/过期和导出。
- 交付继续使用代码更新包、已有镜像和独立 `docker-compose` 命令；不要求目标环境安装 Compose v2、Python 或 npm。
