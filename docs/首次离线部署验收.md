## 内网首次部署

目标机预装 Docker 20.10+、独立 `docker-compose` 1.29+，使用 Bash 和常规 Linux 工具。**不依赖 `docker compose` v2 插件，也不需要宿主 Python、Node、npm、make、jq 或互联网。**当前用户须能访问 Docker，并能写入 `/data`。

将整个 `/data/hcs/deploy` 目录复制到内网机器任意传输位置（保留隐藏的 `.env.example`），进入该目录：

```bash
bash install.sh --check
bash install.sh
```

也可只传完整 `.tar.gz` 和对应 `.sha256`，校验并解压后执行 `bash install.sh`。安装入口不覆盖已有的非空目标目录；重复启动使用：

```bash
cd /data/hcs-inspector
bash deploy.sh
bash deploy.sh status
```

默认 HTTP 80 端口。初始账号 `admin`；随机口令保存在目标目录 `.env` 的 `INSPECTOR_INIT_ADMIN_PASSWORD`，文件权限 `0600`。登录后修改口令并备份 `.env` 中的主密钥。

新装没有演示租户；18 项采集开关、10 项巡检任务全部关闭。正式租户和邮件在系统管理中配置，确认后按需开启。后续只上传代码包，在部署目录执行 `bash deploy.sh update /path/代码包.tar.gz`，不重复传镜像。
