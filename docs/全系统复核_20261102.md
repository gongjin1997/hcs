# 全系统复核（2026-11-02）

本轮按上传的 13 份 PDF 核对现有 14 类资源台账、10 个采集器，以及规则、告警、任务、报表、页面和 XLSX 链路。测试使用独立数据、Mock 和短命 PostgreSQL/Redis；没有读取正式配置或请求正式云服务。文档核对和本地测试不能替代局点 API 联调。

## 指标来源

| 对象 | 当前处理 | 不能据此推断的能力 |
| --- | --- | --- |
| ECS | 原生 API 读取清单、状态及配额；性能使用显式配置的 Prometheus。自定义查询须声明单位，可另配源时间查询和标签条件 | 上传 ECS PDF 未证实单机 CPU/内存/磁盘使用率读取接口；不调用注册类操作。PromQL 求值时间不等于 exporter 物理采样时间 |
| DCS | 使用自身 V2 statistics；保存内存、网络速率、条数和累计计数，缺采留断点 | used_cpu 是累计秒，不是 CPU%；不自动回退旧 V1，也不从 AOM 补数 |
| GaussDB | 原生磁盘 GB、组件、慢 SQL、会话及已完成巡检报告；新增 BUILD_FAILED 和异常 SHUTDOWN 规则 | CPU/内存来自报告的实际字段、单位、节点与原始时间，不宣称实时。没有终止会话、执行 SQL 或扩容入口 |
| DataArts | 按实例身份和原始时间解释状态、时长；批任务 P90 用同工作空间/作业近 24h 成功实例计算 | 不信任无文档的 P90 扩展，不填固定基线；不足最低样本数时为空。默认最低 5 条为本地策略，可在任务设置修改 |
| MRS | 集群状态、组件和节点按原始字段；作业缺失、暂停、未知分开显示 | 当前 V2 作业兼容接口不在上传 MRS PDF 中，页面及导出保留未验证提示 |
| CCE / Kubernetes | 区分 CCE 管理接口与原生 Pod/Event 查询；按 UID、实际 owner、区间增量和条件判断 | 不凭名称猜 Deployment/CronJob；跨时间窗口无法分摊的累计次数不是 0；删除、重建和缺采不算恢复 |
| AOM | 所有资源停用，认证前拒绝请求；旧配置只可清除或保留为停用历史 | 不作为任何资源的自动回退来源 |
| CES | 仅保留显式全局允许且租户选择的兼容通道 | 上传资料缺独立 CES 契约，不能以 AOM 或新版公有云文档认证局点能力 |

## 已修复的共同问题

- **数据完整性**：错误体混入清单、重复页、缺页或身份冲突时不执行资源下线；多挂载卷按实际归属去重，EIP/ELB 使用端口证据关联。负数、非有限数和缺失容量不保留旧值，也不补 0。
- **健康状态**：台账刷新不延长巡检有效期。缺采、部分检查和过期显示未知；无可评分对象显示“—”。已有告警保留，不能靠失联恢复。页面、报表和 `/metrics` 使用相同当前证据口径。
- **连续条件**：状态持续时间按规则、检查项、子对象及执行实例隔离。缺采中断连续次数，新执行不继承旧耗时；只接受明确的正常状态作为恢复证据。
- **项目范围**：运行记录保存 project_ref。任务失败、认证告警和最近成功分别按任务/租户/项目计算；另一个项目成功不能抵消失败。历史项目未知不猜测，也不重复加入当前项目总数。
- **报表**：成功率分母仅实际完成执行，跳过/运行中分列；无样本为空。期末告警按历史状态重建；当前资源容量明确标为生成时数据。容器重启/OOM 使用区间可验证次数。
- **规则管理**：未采集指标不能新建或重新启用规则；已存在规则可以停用。新增 GaussDB 两条状态规则后内置规则共 37 条。
- **权限和云访问**：租户/项目归属在解密及请求前检查；阻止方法覆盖、路径越界和未登记写接口。只保留精确登记的查询 POST。超时预算包含认证、等待、限流和重试。
- **通知**：沿用系统用户和租户权限，不新增独立联系人体系。短信总开关默认关闭，租户配置隔离；本轮没有实际发送。

## 页面与导出

顶栏搜索、统一刷新、租户选择和表格操作位置延续现有布局；不增加宣传口号或版本页脚。总览和大屏明确区分未知和真实 0；任务数量覆盖不齐时不显示伪造总数。ECS 配置表单与 JSON 编辑共用状态，单位、源时间查询及标签筛选参与配置签名。

XLSX 与页面复用查询及权限：保留真实 0 和空白，文本防公式执行；ECS 追加时间语义，批任务追加 P90、样本数和窗口信息。原有列顺序尽量保持，新增字段置于末尾。

## 尚需现场契约确认

1. RDS、DMS Kafka、CSS 的匹配版本 API PDF 未提供；保留既有适配器，只修复与版本无关的数据完整性问题。
2. ELB V3 分页参数在上传材料中的具体接口表与通用描述不完整；不擅自添加或猜测参数。
3. `evs-api2.pdf` 属于 EVS(for 云块存储)，不能覆盖所有普通 EVS 补丁版本。
4. MRS V2 作业、CES 兼容通道和 Prometheus 实际标签/单位仍需局点只读响应确认。当前没有将 Mock 成功标为正式验收。
5. DataArts 当前查询窗口为 24h，低频任务可能不足 P90 样本；不声称覆盖全部长期运行历史。

## 验收结果

- 最终 `make check`：后端 **3916 passed、12 skipped、4 subtests passed**；前端 **748 passed（46 文件）**；Ruff、Mypy、Vue 类型检查和生产构建通过。跳过项包括独立 PostgreSQL 项，另行执行，不计入通过数。
- 脚本回归：LAN 12、离线部署 38、代码包 37、更新器 27、Compose 兼容 15、网络检查 18 项，均通过。
- PostgreSQL 16：全量首轮 3905 通过、16 跳过、2 失败。两处为旧测试夹具：未登记系统用户导致通知拒发，以及按数组首项选择项目。修正后相关 **105 项全部通过**；0015 在 PostgreSQL 和 SQLite 的实际升级/降级/再升级各 **3 项通过**。不把首轮失败伪记为全量通过。
- Redis：独立临时 Redis 的令牌、跨进程限流、查询缓存及相关检查 **135 项通过**；最后一次全量也启用了该测试 Redis。
- 页面：26 个桌面入口检查，无页面脚本错误；6 个移动端入口无页面横向溢出。大屏切租户后接口仅返回所选租户。P90 配置、PromQL 查询/单位/源时间/标签保存及重启后读取通过，短信总开关保持关闭。
- 只读账号：任务修改/执行按钮不可见、直接写请求返回 403；ECS 策略只读；GaussDB 实时查询遵循 task:run 权限。本地查看不开放云端变更。
- XLSX：实际页面下载台账、作业、ECS、DCS、GaussDB、存储趋势及报表；openpyxl 读取工作表结构，验证新列、缺口和文本安全。文件名统一按系统设置时区。
- 隔离测试启动脚本曾在重启时更换开发加密密钥，导致合成凭据解密失败；已修正测试脚本为独立持久密钥后复核原生查询。没有因此放宽产品的加密或云访问校验。
