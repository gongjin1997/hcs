## 系统管理

| 分区 | 保留的 `?tab=` 值 |
| --- | --- |
| 接入与采集 | `tenants`、`switches`、`tasks`、`platform` |
| 人员与权限 | `users`、`roles` |
| 系统设置 | `settings`、`audit` |

只展示当前分区的子标签，最多四项。URL 是当前标签的唯一状态来源；分区与标签切换写入历史，浏览器前进、后退及同页面 query 导航同步更新。保留其他 query 和 hash；`accounts` 仍指向租户接入。非法或未授权标签回退到首个可访问项，空分区隐藏；租户范围用户仍不显示全局用户管理。

## 资源关联入口

资源台账详情和有关联本地资源的 GaussDB 告警详情增加“查看 GaussDB 监控”：

`/gaussdb?instance_id=<台账本地主键>&tenant_id=<该资源或告警的租户>`

只在 `ledger:view` 且目标租户属于当前用户范围时显示。不使用云端 `resource_id`、告警 ID 或顶栏筛选代替本地主键和目标租户；缺少关联或明确租户时不产生链接。原 ECS 指标趋势入口保留。

## 可验证路径

1. 管理员依次打开五个作业 URL，点击页内导航并前进、后退，确认标题、面包屑和侧栏“作业运行”选中状态一致；无 `report:view` 的用户直接访问应进入 `/403`。
2. 从 `/system?tab=accounts` 进入，切“人员与权限 → 角色与权限 → 系统设置”，前进、后退并检查 URL、分区及标签同步。以只读和租户范围身份检查分区过滤。
3. 从 GaussDB 台账详情、GaussDB 告警详情点击入口，核对两个 query 使用本地资源和所属租户；缺少权限、租户范围或资源关联时应无入口。
