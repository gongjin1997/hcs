# 资源分类映射

## 用途与边界

资源分类是台账上的独立展示和筛选维度，通过可配置映射计算得到。

| 维度 | 来源 | 示例 |
| --- | --- | --- |
| 云资源类型 | HCS 采集结果，`resource_type` | `ecs_server`、`vpc` |
| 业务系统 | 台账人工维护，`business` | 已登记的业务系统 |
| 资源分类 | 本文的有序映射规则 | MRS、CCE、HIS、其他 |

映射不会修改云服务、云资源类型、业务系统、负责人或其他人工管理字段，不增加资源模型列。
列表、详情和 Excel 在读取时使用当前规则计算结果，保存规则后立即生效；历史资源和已释放资源也不做批量回写。

## 默认规则与数据核验

默认仅检查 ECS 的 `attrs.os`（台账导出的“操作系统”列），按以下顺序首次命中：

| 规则 ID | 资源类型 | 字段 | 字面包含内容 | 分类 |
| --- | --- | --- | --- | --- |
| `ecs-os-mrs` | `ecs_server` | `os` | `MRS` | MRS |
| `ecs-os-cce` | `ecs_server` | `os` | `CCE` | CCE |
| `ecs-os-his` | `ecs_server` | `os` | `his` | HIS |

匹配忽略大小写；未识别、缺少操作系统、操作系统不是字符串、没有适用规则的资源统一归入“其他”。
默认不根据资源名称、资源 ID、IP 地址或业务系统猜测分类。操作系统同时包含多个规则内容时，以映射表顺序为准。

对 2026 年 11 月 2 日提供的本地资源台账做了一次仅读取“操作系统”列的核验，200 条 ECS 的结果为：

| 分类 | 条数 |
| --- | ---: |
| MRS | 51 |
| CCE | 101 |
| HIS | 27 |
| 其他 | 21 |
| 合计 | 200 |

以上仅为所提供文件的聚合核验结果，不代表当前部署数据库的资源数量。
仓库只保留规则和汇总，不包含该原始 Excel、私有资源 ID、IP 或资源名称。自动化测试使用合成资源。

## 配置格式

配置由分类服务直接保存到 `sys_setting` 的 `resource_classification` 键；通用系统设置接口不维护此键。
没有保存记录时使用默认规则。历史配置损坏时读取默认规则并记录不含配置正文的告警日志，不覆盖原始配置。

```json
{
  "rules": [
    {
      "id": "ecs-os-mrs",
      "resource_type": "ecs_server",
      "field": "os",
      "pattern": "MRS",
      "category": "MRS",
      "enabled": true
    },
    {
      "id": "ecs-os-cce",
      "resource_type": "ecs_server",
      "field": "os",
      "pattern": "CCE",
      "category": "CCE",
      "enabled": true
    },
    {
      "id": "ecs-os-his",
      "resource_type": "ecs_server",
      "field": "os",
      "pattern": "his",
      "category": "HIS",
      "enabled": true
    }
  ],
  "fallback": "其他"
}
```

- 最多 200 条规则；规则 ID 必须非空、唯一，最多 64 个字符。
- `resource_type` 必须是已有资源类型目录中的代码，允许为其他资源类型增加独立规则。
- `field` 仅允许 `os`、`name`、`business`、`spec`；`os` 对应 `attrs.os`，其他字段对应资源同名字段。
- `pattern` 去除两端空白后非空，最多 128 个字符；`category` 和 `fallback` 非空，最多 64 个字符。
- 按列表顺序跳过禁用规则，对字段文本及 `pattern` 做 `casefold` 后进行字面包含匹配，首次命中即停止。
- 不执行正则表达式，不把 `%`、`_`、`*` 等字符作为通配符。
- 空规则列表合法，全部资源使用 `fallback`。默认回退值为“其他”，也可显式配置其他名称。

## API 与权限

### 读取映射和数量

`GET /api/v1/resources/classifications`，需要 `ledger:view`。

返回统一响应信封，`data` 包含：

- `rules`、`fallback`：全局映射配置。
- `categories: string[]`：按规则顺序去重的启用分类，最后包含回退分类；保留零条资源的已配置分类。
- `counts: Record<string, number>`：各分类的在用资源条数。
- `total: number`：上述条数合计。
- `customized`、`updated_by`、`updated_at`：保存状态和最近维护信息。

数量按当前用户租户范围及 `X-Tenant-Id` 过滤。可使用 `resource_type=ecs_server` 或已有的 `category` 参数
限定计数所用的资源类型；配置 `rules` 本身仍返回完整的全局映射。无数据权限时返回零计数，不退回全部租户。

`GET /api/v1/resources/types` 增加同样的 `classifications: {categories, counts, total}`，
接受上述 `resource_type` / `category` 参数限定分类选项和数量。原有云服务分类、业务系统字典、负责人目录保持各自含义。

### 保存映射

`PUT /api/v1/resources/classifications`，需要 `ledger:edit` 和全部租户数据权限。

请求体只发送完整的 `rules`、`fallback`，不要回传只读的数量或元数据。保存整体替换映射表，
记录 `ledger.classification` 操作审计并返回保存后的规则、数量和维护信息。受限租户用户不能修改全局规则。
规则字段、长度、重复 ID 或资源类型不合法时拒绝整个请求，不部分保存。

### 资源结果与筛选

资源列表、资源详情及资源管理字段修改响应中的 `ResourceOut` 增加：

- `classification: string | null`：当前计算出的分类；资源接口返回分类或回退值。
- `classification_source: string | null`：命中的规则 ID；回退分类为 `null`。

其他使用 `ResourceOut` 而未主动计算分类的接口可以保持默认 `null`。

`GET /api/v1/resources?resource_type=ecs_server&classification=MRS` 按分类筛选，
可以与现有租户、业务系统、负责人、状态等条件组合。分类条件在数据库 SQL CASE 中计算，先筛选再分页，
`total` 为匹配资源总数；SQLite / PostgreSQL 使用相同的有序规则。
非 ASCII 候选文本会补齐数据库大小写转换与 Python `casefold` 的差异，保证显示和筛选结果一致。

## Excel 导出

`GET /api/v1/resources/export?resource_type=ecs_server&classification=MRS`，需要原有 `ledger:export` 权限。

各资源明细表在原有列之后追加“资源分类”列，原来的“业务系统”“环境”等列及位置不变。
导出使用当前保存规则，与资源列表的分类筛选及租户权限一致；汇总页显示筛选分类和导出资源总数，审计记录筛选值。
分类没有匹配资源时仍返回包含表头的合法工作簿。

台账人工字段导入模板、负责人导入规则和业务系统字典不因分类映射改变。
